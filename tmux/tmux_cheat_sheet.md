# tmux チートシート

プレフィックスキー: **Ctrl+b** （デフォルトのまま）

## 用語

セッション > ウィンドウ > ペイン

## セッション

| 操作 | キー / コマンド |
|---|---|
| 新規作成 | `tmux new -s セッション名` |
| 一覧表示 | `tmux ls` |
| アタッチ | `tmux a -t セッション名` |
| デタッチ | `C-b d` |
| セッション一覧 (tmux内) | `C-b s` |
| セッション終了 | `tmux kill-session -t セッション名` |

## ウィンドウ

| 操作 | キー |
|---|---|
| 新規作成 | `C-b c` |
| 次へ | `C-b n` |
| 前へ | `C-b p` |
| 番号指定で移動 | `C-b 番号` |
| 名前変更 | `C-b ,` |
| 左へ入れ替え | `C-b <` |
| 右へ入れ替え | `C-b >` |
| 終了 | `C-b &` |

## ペイン

| 操作 | キー |
|---|---|
| 左右に分割 | `C-b \|` |
| 上下に分割 | `C-b -` |
| 左に移動 | `C-b h` |
| 下に移動 | `C-b j` |
| 上に移動 | `C-b k` |
| 右に移動 | `C-b l` |
| ペイン番号を表示 | `C-b q` |
| ペインを閉じる | `C-b x` |
| 他ウィンドウのペインを取り込む | `C-b J` |
| ペインをウィンドウに分離 | `C-b !` |

## コピーモード (vi キーバインド)

| 操作 | キー |
|---|---|
| コピーモード開始 | `C-b [` |
| 選択開始 | `v` |
| コピー＆終了 (クリップボード) | `Enter` |

## その他

| 操作 | キー / コマンド |
|---|---|
| 設定リロード | `C-b r` |
| Ctrl+b をアプリに送る | `C-b C-b` |
| コマンドモード | `C-b :` |

## 主な設定値

| 設定 | 値 |
|---|---|
| マウス操作 | 有効 |
| ウィンドウ番号開始 | 1 |
| ペイン番号開始 | 1 |
| ステータスバー位置 | 上部 |
| Escキー遅延 | 0ms |
| スクロールバック行数 | 50000 |
| ウィンドウ番号の自動詰め | 有効 |
| ターミナル | tmux-256color (TrueColor対応) |
| allow-passthrough | 有効 |
| コピーモード キーバインド | vi |
